# Open English Translation Literal Version (OET-LV): Deuterocanonical books

This folder contains the ESFM files for the _OET Literal Version_ of the deuterocanonical/apocryphal books,
along with the word table that the ESFM word numbers refer to.

These files are generated by [scripts/build_OET-LV_DC.py](../../scripts/build_OET-LV_DC.py) and then edited by
[ScriptedBibleEditor](https://github.com/Freely-Given-org/ScriptedBibleEditor) using
the command tables in [scripts/ScriptedDCUpdates](../../scripts/ScriptedDCUpdates/).
Please don’t edit them by hand: your changes will be overwritten by the next build.
[version.json](version.json) records the build inputs and content fingerprint.
