# Open English Translation Literal Version (OET-LV): Messianic Update

This folder contains the ESFM files for the _OET Literal Version_ of the Messianic Update (‘New Testament’),
along with the word table that the ESFM word numbers refer to.

These files are generated by the scripts in the [scripts folder](../../scripts/) and then edited by
[ScriptedBibleEditor](https://github.com/Freely-Given-org/ScriptedBibleEditor) using
the command tables in [scripts/ScriptedVLTUpdates](../../scripts/ScriptedVLTUpdates/).
Please don’t edit them by hand: your changes will be overwritten by the next build.
[version.json](version.json) records the build inputs and content fingerprint.
